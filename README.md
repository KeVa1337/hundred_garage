# Hundred Garage — сайт автосервісу (демо)

Клікабельне демо сайту автосервісу: публічна частина, онлайн-запис, кабінет клієнта, бонусна програма, чат і адмін-панель.
Демо працює без сервера — дані зберігаються в браузері (localStorage), тож його можна просто відкрити і показати клієнту.

## Як запустити

```bash
python3 -m http.server 8080
# відкрити http://localhost:8080
```

Або увімкнути GitHub Pages для гілки — збирати нічого не потрібно.

У лівому нижньому куті є панель **ДЕМО**: перемикання ролей *Гість / Клієнт / Адмін* і кнопка ↺ (скинути дані).
Якщо відкрити сайт і адмінку у двох вкладках, чат і статуси синхронізуються наживо.

| Роль | Як увійти |
|---|---|
| Клієнт | кнопка «Клієнт» або номер `+380 67 123 45 67`, будь-який код із 4 цифр |
| Адмін | кнопка «Адмін» або логін `admin`, пароль `demo` |
| Відстеження | замовлення `HG-24117`, останні цифри телефону `4567` |

## Що є в демо

**Сайт**
- Головна з «табло цеху»: завантаженість 4 постів наживо (номери авто приховані).
- Послуги і ціни з калькулятором за типом авто (легковий / SUV / бус / преміум) і кошиком.
- Онлайн-запис за 4 кроки: послуги → авто → вільний слот → контакти. Попередній розрахунок у формі наряд-замовлення.
- «Де моє авто?» — відстеження ремонту за номером замовлення.
- Сторінка бонусної програми з калькулятором кешбеку, відгуки, FAQ, контакти, замовлення дзвінка.
- Світла і темна теми, адаптивна верстка під телефон.

**Кабінет клієнта**
- Активне замовлення з етапами ремонту.
- **Погодження робіт**: знахідки огляду (критично / можна відкласти / в нормі), рішення «Робити / Пізніше» по кожному пункту.
- **Запчастини**: кожна позиція окремим рядком (бренд, артикул, ціна, статус). Для пропозицій — вибір «Оригінал / Аналог / Привезу свою / Не треба».
- Знижки і оплата балами (до 30% чеку) видно в розрахунку.
- Мій гараж: пробіг, план ТО з прогресом, сервісна книжка з відкладеними роботами.
- Бонуси: баланс, рівень, історія, код запрошення друга. Профіль і налаштування повідомлень.

**Адмін-панель**
- Панель: KPI, розклад постів по годинах, нові заявки, виручка за 14 днів, структура робіт.
- Замовлення: фільтри, пошук, редактор (статус, пост, майстер, знахідки огляду, запчастини, знижка). Клієнт бачить кожну зміну одразу і отримує повідомлення в чат.
- **Запчастини**: зведений список «треба замовити / в дорозі / чекаємо від клієнтів / на складі». Коли прибуде остання запчастина, замовлення само переходить у «Ремонт».
- Клієнти: картка, ручне нарахування балів, персональна знижка.
- Послуги і ціни (редагування на льоту), чат з клієнтами, модерація відгуків, налаштування бонусної програми й акцій.

**Чат на сайті** — автовідповідач миттєво відповідає на типові питання (ціни, запис, статус авто, бали, запчастини, графік). Усе листування потрапляє в адмінку.

## Логіка запчастин і знижок

- Під час запису клієнт обирає: *сервіс підбирає і замовляє*, *привезу свої* або *вирішу після огляду*.
- Майстер додає запчастини: назву, бренд, артикул, кількість, ціну, наявність або термін постачання і, за бажанням, аналог.
- Позиції, які потребують згоди клієнта, мають статус «Пропозиція». Без рішення клієнта сервіс їх не замовляє.
- Статуси запчастин сервісу: пропозиція → треба замовити → в дорозі → на складі → встановлено.
  Запчастини клієнта: чекаємо від клієнта → отримано → встановлено.
- Якщо після погодження щось треба замовити, замовлення переходить в етап «Очікуємо запчастини».
- Знижка задається у відсотках або гривнях — на роботи, на запчастини чи на весь чек, з причиною, яку бачить клієнт.
  Персональна знижка клієнта автоматично підставляється в нові замовлення.
- Підсумок: роботи за прайсом + погоджені додаткові роботи + запчастини сервісу − знижка − оплата балами.

## Структура

```
index.html        оболонка сторінки
css/app.css       дизайн-система і всі стилі
js/store.js       дані демо та бізнес-логіка (статуси, бонуси, запчастини, знижки)
js/ui.js          форматування, іконки, модальні вікна, сповіщення
js/app.js         маршрутизація, вхід, демо-перемикач ролей
js/public.js      публічні сторінки
js/booking.js     онлайн-запис
js/cabinet.js     кабінет клієнта
js/admin.js       адмін-панель
js/chat.js        чат-віджет і автовідповідач
```

## Що потрібно для робочої версії

Демо імітує сервер у браузері. Для запуску з реальними клієнтами потрібні:
1. Бекенд і база даних (наприклад, Node.js/NestJS + PostgreSQL) з тими самими сутностями: клієнти, авто, замовлення, позиції запчастин, бонусні операції, чати.
2. Вхід за SMS-кодом (TurboSMS, AlphaSMS тощо) і повідомлення у Viber/Telegram.
3. Ролі персоналу (адміністратор, майстер, власник) та журнал змін.
4. Чат у реальному часі (WebSocket) і push-сповіщення.
5. Онлайн-оплата (LiqPay / monobank), фіскальні чеки.
6. Інтеграція з постачальниками запчастин (пошук за VIN/артикулом, ціни, наявність), за потреби — з обліковою системою (1С/BAS).
7. Фото й відео огляду, які майстер додає з телефона.
